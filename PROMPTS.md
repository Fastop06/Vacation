# Промпты для картинок — Nano Banana 2 (запасной вариант)

> **Важно:** сейчас в презентации уже стоят **настоящие фотографии Швейцарии**
> из Wikimedia Commons (свободные лицензии) — они лежат в папке `images`
> и подставляются автоматически. Список авторов и лицензий — в файле `CREDITS.md`.
>
> Этот файл нужен, если ты захочешь **заменить** фотографии на сгенерированные.
> На сайте для этого ничего нажимать не надо — просто положи новые файлы в `images`.

**Как заменить фото на сгенерированные:**
1. Скопируй нужный промпт отсюда.
2. Вставь в Nano Banana 2 → сгенерируй → сохрани как `images/1.jpg`, `images/2.jpg`, …
3. Обнови страницу (⌘R).

## Как вставить свои фото

Фотографии подставляются автоматически: в `index.html` у каждого блока картинки
стоит атрибут `data-img` с номером, а `app.js` ищет файл `images/<номер>.jpg`.

```html
<figure class="shot sky-1 ridge-a" data-img="1">
```

Так что чтобы заменить фото, достаточно положить свой файл в папку `images`
с этим именем. Больше ничего править не нужно.

Чтобы совсем убрать фото — удалите атрибут `data-img` у тега `<figure>`,
тогда останется нарисованная заглушка.
