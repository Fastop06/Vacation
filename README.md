# My Perfect Vacation — Zermatt, Switzerland

Презентация-сайт на английском: **17 слайдов** про отпуск в Зермате (Швейцария, Маттерхорн).
Минимализм: бело-серый фон, насыщенный хвойный зелёный, минимум текста, максимум фотографий.
Переход между слайдами — **пролетающий самолёт с облаками**.

## Запуск

Открой `index.html` в браузере. Всё.

Через локальный сервер (фото подгрузятся так же):

```bash
cd "Default Project"
python3 -m http.server 8765
# затем открой http://localhost:8765
```

## Управление

Никаких кнопок на экране — только:

| Действие | Как |
|---|---|
| следующий слайд | `→` · `Space` · клик · колесо мыши вниз · свайп влево |
| предыдущий слайд | `←` · колесо мыши вверх · свайп вправо |
| первый / последний | `Home` / `End` |

| Файл | Что это |

## Про фото

16 фотографий с Wikimedia Commons под свободными лицензиями
(CC BY, CC BY-SA, Public Domain). Авторы указаны в `CREDITS.md` — этого достаточно,
чтобы использовать их в школьной презентации.

## Если хочешь другие фото

Положи файлы `1.jpg` … `16.jpg` в папку `images` — они подставятся сами,
атрибуты трогать не нужно. Или сгенерируй по промптам из `PROMPTS.md`.
